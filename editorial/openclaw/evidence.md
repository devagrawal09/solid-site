# OpenClaw case study: evidence for the editor

The three articles use the same comparisons. Here is what was counted, and what the comparisons establish.

| Claim | Before / after | Source and scope |
| --- | --- | --- |
| Removing direct Lit imports | 800 → 0 production files | Run the same [inventory checker](https://github.com/openclaw/openclaw/blob/997b324c252b678287d6a5f57e1c1fa9d08656aa/scripts/control-ui-solid-inventory.mts) at the [baseline](https://github.com/openclaw/openclaw/tree/88b4ae9fba33e59bf9e23a4be29d09df34a01a83) and [cutover](https://github.com/openclaw/openclaw/tree/399b740ce0412ccf34b41fb8e7dca7ddb6ad0a68); roots `ui/src`, `extensions/workboard/browser`, `extensions/x/src`. This is a file count, not 800 components. |
| Core UI files directly importing a Solid runtime value | 776 → 989 → 1,126 | [Oct 16](https://github.com/openclaw/openclaw/tree/399b740ce0412ccf34b41fb8e7dca7ddb6ad0a68), [Oct 31](https://github.com/openclaw/openclaw/tree/a6296100c8d007f720ae9da827e04297ebe317fd), [Nov 24](https://github.com/openclaw/openclaw/tree/2d17819c2faacd5d2a2d70991b438cfb33affee3), all on `main`. From tracked TS/TSX in `ui/src`, omitting test, fixture, benchmark and declaration paths. Count runtime-value imports of `solid-js`, `@solidjs/web`, `@solidjs/signals` and subpaths, not types. Total files examined: 2,413 → 2,870 → 3,221. |
| Direct calls to `createEffect` | 323 → 86 → 85 | Same trees and scope. Count call expressions whose callee is a named imported identifier, including aliases. Excludes wrappers, generated code and indirect calls. This does not measure reactive executions. |
| Streaming renders and CPU | 353 → 1 whole-pane renders; median script CPU 3,997 → 1,957 ms | [OpenClaw’s benchmark](https://github.com/openclaw/openclaw/pull/180884): ten interleaved production-browser pairs, synthetic Gateway, 400 messages, 645 updates. Both sides ran Solid; median per-run p95 frame gap was unchanged. |
| Directly referenced entry JS | 351,881 → 93,928 gzip bytes (−73.3%) | [v11.4 HTML](https://unpkg.com/openclaw@2026.11.4/dist/control-ui/index.html) → [v11.5 HTML](https://unpkg.com/openclaw@2026.11.5/dist/control-ui/index.html). Count distinct external JS scripts and preload links referenced directly outside conditional route templates. Excludes inline JS, transitive imports and route traffic. |
| All shipped dashboard JS | 10,583,614 → 12,342,151 gzip bytes (+16.6%) | Same releases. From the [v11.4](https://registry.npmjs.org/openclaw/2026.11.4) and [v11.5](https://registry.npmjs.org/openclaw/2026.11.5) npm archives, count every regular `.js` under `package/dist/control-ui/`, including lazy chunks. Both size comparisons sum independently gzipped files at level 9, not HTTP transfer measurements. |
| The matched double-teardown check | Both original suites passed 4/4; both caught the same injected fault | Take the [Lit fixture](https://github.com/openclaw/openclaw/blob/88b4ae9fba33e59bf9e23a4be29d09df34a01a83/ui/src/components/mcp-app-unmount.test.ts) and [ported fixture](https://github.com/openclaw/openclaw/blob/3be41182be9b09709f3e6c038c46aeb7d633841d/ui/src/components/mcp-app-unmount.test.ts) with their production helpers. In disposable copies disable the early return when teardown is already pending. Both fail on the second replacement: expected one teardown, observed two. This is one isolated jsdom comparison, not proof of equal total coverage. |

### Publication notes

- “Ada” and “Grace” belong to the [Solid regression test](https://github.com/solidjs/solid/blob/6cca8b574decd20e8ca495a9376e735b6bc5655a/packages/web/test/uncommitted-input-overwritten.spec.tsx). The [custom model-name repair](https://github.com/openclaw/openclaw/pull/191045#issuecomment-6576819002) was a later OpenClaw field. The RC.17 warning does not automatically save user text.
- The [Workshop change](https://github.com/openclaw/openclaw/pull/202572) is described on `main`; it was ahead of the Nov 24 stable snapshot. Merge and release can fall on different dates.
- Recheck [the stable-upgrade PR](https://github.com/openclaw/openclaw/pull/200929) and the latest tagged `ui/package.json` before publishing. As checked for this draft, the PR was open and [v2026.11.10](https://github.com/openclaw/openclaw/blob/v2026.11.10/ui/package.json) still pinned RC.18. Its [hosted size job](https://github.com/openclaw/openclaw/actions/runs/44328896796/job/134889074113) passed; [aggregate CI](https://github.com/openclaw/openclaw/actions/runs/44328896796) did not. Some failing layout tests were also reproduced on `main`.
