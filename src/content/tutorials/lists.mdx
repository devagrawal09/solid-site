# Lists by identity

`For` normally tracks each item by its identity. Reordering items preserves their DOM and owned state. The callback receives the raw item and a reactive index getter:

```jsx
<For each={cats()}>
  {(cat, index) => (
    <li>
      {index() + 1}: {cat.name}
    </li>
  )}
</For>
```

The item's identity is stable for that row. If an item is a store object, keep reads of its changing fields inside JSX or another reactive computation.

**Try it:** replace `map` with `For` and use the index getter for the displayed position. Use identity mapping when rows represent distinct entities. The next lesson compares position mapping.
